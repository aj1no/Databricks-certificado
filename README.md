## Getting Started

1. **Prerequisites:**
   To run the notebooks locally, you need Python and PySpark installed:
   ```bash
   pip install pyspark jupyter
   ```

2. **Running the Notebooks:**
   Launch Jupyter Notebook in the repository root:
   ```bash
   jupyter notebook
   ```
